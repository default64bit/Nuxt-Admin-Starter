# ADR-0001: Record architecture decisions

- **Status:** Accepted
- **Date:** 2026-11-08

## Context

Decisions made in chats and heads get lost. New contributors and coding agents cannot tell deliberate choices from accidents.

## Decision

We will record significant decisions as ADRs in `docs/adr/`, using the template in `0000-template.md`, reviewed through pull requests. Accepted ADRs are immutable; changes happen by superseding.

## Consequences

- Positive: shared memory, faster onboarding, fewer repeated debates.
- Negative: small writing overhead per decision. Keep ADRs to about one page.
